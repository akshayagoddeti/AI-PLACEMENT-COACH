# 🔭 FutureLens AI
> Your AI-powered direction system for student career and placement preparation.
## 📌 About the Project
FutureLens AI is an AI-powered student career and placement preparation platform built using Python and Streamlit.
It combines resume analysis, job matching, AI study assistance, mock interviews, coding practice, performance analysis, and personalized placement planning into one application.
## ✨ Features

### 🏠 Dashboard
- Placement readiness score
- Preparation progress
- Resume status
- Job match status
- Interview statistics
- Coding practice status

### 📄 Resume Analyzer
- Upload resume PDF
- Extract resume information
- Identify skills and projects
- Find strengths and weaknesses
- Identify missing skills
- Get AI-based suggestions

### 💼 Job Match
- Upload resume
- Upload job description
- Generate match score
- Find matching skills
- Find missing skills
- Get preparation suggestions

### 🧠 AI Study Assistant
- Upload study PDFs
- RAG-based question answering
- ChromaDB knowledge base
- Retrieve relevant study content
- AI-generated answers
- View sources used

### 🎤 AI Mock Interview
- HR Interview
- Technical Interview
- Mixed Interview
- AI-generated questions
- Text-to-speech questions
- Text/audio answer support
- AI answer evaluation
- Interview history

### 💻 AI Coding Interview
- Java, Python, C and JavaScript
- Easy, Medium and Hard difficulty
- AI-generated coding problems
- Code submission
- AI code evaluation
- Complexity analysis
- Improvement suggestions

### 📊 Performance Report
- Overall interview score
- Strengths
- Weaknesses
- Communication feedback
- Technical knowledge analysis
- Improvement areas
- Downloadable report

### 🗺️ Placement Roadmap
- Personalized 4-week roadmap
- Weak-area identification
- Daily preparation routine
- Priority skills
- Project improvement suggestions
- Placement preparation tips

## 🛠️ Technologies Used

- Python
- Streamlit
- Ollama
- Llama 3.2
- PyPDF
- ChromaDB
- RAG
- HTML/CSS
